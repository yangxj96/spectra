## 1. 本阶段实现

### 1.1 应用用例授权与跨域端口

- 管理用例在 Service 层增加最终 `@PreAuthorize` 校验，不再只依赖 Controller 粗授权。
- 按 B07 台账列出的位置完成定向端口化：安全菜单/角色菜单、用户目录与安全状态、部门目录与组织变更、DevOps 收件人、目录查询、授权编排、服务监控告警和候选人查询。
- 移除 `DirectoryQueryAdapter`、`OrganizationChangeServiceImpl`、`AuthorizationAssignmentChangeServiceSupport`、`ServiceMonitorAlertServiceImpl`、`SecurityTargetCandidateServiceImpl`、`MenuServiceImpl`、`RelRoleMenuServiceImpl` 等对对方域 Mapper 的直连。
- `GrantBoundaryViolationException` 继承 `AuthorizationDeniedException`，统一映射 HTTP 403 `ACCESS_DENIED`。

### 1.2 不变量与边界

- 菜单删除：存在活动子节点时拒绝；叶子节点在同一事务删除角色菜单关系后软删除。
- 身份：同一用户同一联系方式类型只保留一个活动身份。
- 用户批量删除：先全量校验目标和权限，再整体提交；任一无权限或不存在 ID 都返回失败，不部分成功。
- Secret 拆分管理与供给端口：管理端使用 `SecretManagementService`，可信启动/运行链路使用 `SecretProvisioningService`。

### 1.3 有界查询

- 通知模板 `page`、`groupPage` 使用数据库窗口函数分页，计数与分页查询分离。
- 通知模板版本历史改为数据库 `COUNT + LIMIT/OFFSET` 真分页，固定版本号倒序，拒绝客户端排序；Web 版本历史同步为分页契约并提供分页控件。
- 版本分页每页限制在 1–100，避免请求页大小放大数据库工作量。
