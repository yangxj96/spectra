# B02 Workflow 流程实例通知身份验证

## 范围与调用方

本项核对 `DIAG-CORE-034`、`IMP-CORE-007`、`CHECK-CORE-034` 的 Workflow 流程实例通知调用。CodeGraph 和当前源码显示：`TaskServiceImpl.complete/reject` 在任务动作后调用 `notifyWorkflowResult` 与 `notifyNextTasks`，使用登记的 `WORKFLOW_TASK` 通知系统身份，并按明确办理人登录名解析用户 ID。`ProcessInstanceServiceImpl.start` 负责启动 Flowable 实例。Web 的 `workflow-api.ts` 和 OA 审批中心调用既有 `1.0.0` 任务端点，本项没有改变接口契约或 Web 代码。2026-10-22 后续定点核对 OA 报销驳回回调：Workflow 完成任务后按流程 KEY 分发 `ReimbursementApprovalCallback`，业务 Service 回写申请状态并使用 `OA_WORKFLOW_RESULT` 身份写入站内通知。
