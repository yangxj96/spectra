# B02 会议以外分页入口正式 HTTP 验证

## 范围与影响

本项为 `BC-BASE-008`（`DIAG-BASE-002`）补齐会议以外的**其他分页业务入口**与**正式 Core 身份装配**证据：真实 Core 用户登录后，用户分页入口只接受已注册排序字段并拒绝恶意表达式，审计分页固定排序入口明确拒绝客户端排序。后端 CodeGraph 与源码确认：`UserServiceImpl.page` 用 `PageFrom.toPage(Map.of("id","id","username","username","real_name","real_name","employee_no","employee_no","created_at","created_at"))`，未知列映射为 null 即 `IllegalArgumentException`；`AuditLogQueryService.page` 调用 `PageFrom.requireUnsorted()`。本项没有改动端点、排序契约或生产源码。

## 可观察行为

1. **已注册字段接受**：`GET /api/user/page?...&orders[0].column=username` 返回 200。
2. **恶意表达式拒绝**：`orders[0].column=username;drop table ...` 与未注册的 `orders[0].column=password_hash` 返回 400。
3. **固定排序拒绝**：`GET /api/audit/page?orders[0].column=id` 返回 400，而同一入口无排序时返回 200。
