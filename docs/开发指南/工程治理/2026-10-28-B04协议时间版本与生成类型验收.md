# B04 协议、时间、编辑版本与生成类型验收

- 日期：2026-10-28
- 范围：B04 批次，`DIAG-CORE-003/004`、`DIAG-WEB-005/006/008/014/016`，以及 B04 行为检查
- 环境：原生 Windows PowerShell 7、mise `test` 环境、JDK 25、Maven Wrapper、PostgreSQL `devops00_spectra_db_test`、Redis DB 5、Vite 8、Chrome/Playwright
- 约束：未读取或输出数据库密码、Redis 密码、Token 或私钥；浏览器与 HTTP 均只使用测试库和合成数据

## 1. 实现结果

### 1.1 后端编辑版本与清空语义

- 用户、个人资料、菜单、字典组、字典项、行政区划、系统配置、Quartz Job 均接收客户端读取版本。
- MyBatis-Plus `@Version` 路径在版本条件不满足时返回 `ENTITY_UPDATE_CONFLICT` / HTTP 409。
- Quartz 使用 `spectra_quartz.QRTZ_JOB_DETAILS.EDIT_VERSION` 显式条件更新，和 Job 参数 `schema version` 分离；新增 Flyway `V9__quartz_job_edit_version.sql`。
- `User.departedAt` 改为 `FieldStrategy.ALWAYS`，重新入职时可清空 `departed_at`；用户 `language/timezone`、菜单 `pid/route_name`、字典 `pid/remark`、区域可空字段、配置 `remarks` 的 ALWAYS 清空策略保持不变。
- Region 新增 `GET /api/region/{id}`，编辑入口可读取当前版本。
- 用户编辑继续显式拒绝手机号/邮箱修改，避免静默忽略。
- `UserPageVO`、`UserProfileVO` 的 `departedAt/createdAt` 改为 `OffsetDateTime`，HTTP 时间字段带偏移。

### 1.2 契约与生成类型

- 新增运行时 OpenAPI 导出：`OpenApiConfiguration`、`OpenApiExportTest`，固定 OpenAPI 3.1.0 / API 1.0.0。
- 契约统一 snake_case、成功响应 data 包装、`ApiErrorEnvelope`、4xx/409/416/503 错误响应、编辑视图 `version` 必填、可清空字段 `null` 类型。
- 前端新增 `scripts/contracts.mjs`、`contracts/openapi.json`、`src/api/generated/openapi.ts`，提供 `contract:generate` / `contract:check` 漂移检查。
- `types/system/bootstrap.d.ts`、`configured.d.ts`、`scheduler.d.ts` 的响应类型改为从生成契约派生；页面表单模型继续手写，符合前端“薄 API + 页面模型手写”约束。
- 前端错误只读取 `error_code`，删除 `code`、嵌套 `data`、`x-error-code` 等回退；时间工具不再用浏览器时区重新解释服务端墙上时间。

### 1.3 前端版本冲突恢复

- Profile、用户、菜单、区域、字典组、字典项、系统配置、Quartz 任务编辑均提交读取版本。
- 409 时保留当前草稿，提示最新版本并允许“核对后采用新版本”重新提交。
- 浏览器实测系统配置页：后台并发更新后保存返回 409，草稿“B04 draft kept”保留；采用最新版本后重新保存成功，数据库值为“B04 draft kept”且版本递增。
