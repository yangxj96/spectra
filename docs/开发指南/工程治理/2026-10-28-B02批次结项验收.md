## 定点验收例外与风险

用户确认本机无法直接执行的联机/异机环节可在明确记录未运行事实后作为本批完成的定点例外。这里的 `completed` 表示 B02 交付与本机可执行验收收口，**不表示下列测试已经运行或风险已消失**。

1. **真实跨主机与单端网络故障未运行。**本机两个独立 JVM、隔离 Redis/TCP 转发器、故障恢复和最后 Root 竞争已执行。风险是跨主机网络设备、时钟或连接池行为可能不同；上线仍需运维观察 Redis/数据库就绪、401/503 和撤销传播。
2. **生产历史 Session 滚动部署与清理未运行。**合成旧格式 Access/Refresh 缺原始截止时间均拒绝。风险是旧登录用户会被强制重新登录；部署时应告知用户并按当前协议淘汰旧记录，不读取真实业务数据做本批迁移或故障测试。
3. **真实进程在 PostgreSQL 提交瞬间崩溃未运行。**当前调用顺序为先 Redis 撤销、再数据库事务提交；合成数据库回滚证实旧 Session 已失效、账号可重新登录。风险是跨存储不具原子性，故障可造成额外重新登录；不得声称分布式原子提交。
4. **OA/Workflow 每个 `@Audit` 入口逐一真实 HTTP、所有业务分页逐一 HTTP 及浏览器排序交互未运行。**B02 的共同审计切面、清洗器和排序白名单已测试，代表性 Core/OA/Workflow 正式 HTTP 与 54 项调用边界通过；风险是个别业务入口的独立字段或查询映射仍可能有缺陷，归其业务批次继续验证，不能将抽样测试写成全入口实测。
5. **Web 与真实后端的完整浏览器身份失效流程未运行。**本轮只验证合成审计 API 的页面消费；B02 当前后端改动没有新增 API 契约或旧读取分支。B08 继续负责页面级身份失效的独立验收，B02 的完成不替代 B08。

本批验收例外不改变共享影响项的未完成状态，也不推定 B03–B10 或整个治理周期完成。
